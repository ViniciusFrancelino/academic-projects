# Projetos acadêmicos — Análise e Desenvolvimento de Sistemas

Repositório que reúne projetos desenvolvidos ou dos quais participei ao longo do curso de **Análise e Desenvolvimento de Sistemas (ADS) na São Paulo Tech School (SPTech School)**. A lista está organizada do mais antigo ao mais recente.

## Projetos

### The Bulworth Machine

- **Período:** 1º semestre do curso — 2º semestre de 2025
- **Participação:** Individual
- **Projeto:** Conversor de números entre as bases decimal, hexadecimal, octal e binária, com interface temática inspirada no jogo *Bully*. Desenvolvido para praticar a estruturação de páginas, a estilização com CSS e a lógica de conversão em JavaScript.
- **Arquivos:** [TheBulworthMachine](./TheBulworthMachine/)

### Verbum Dei

- **Período:** 1º semestre do curso — 2º semestre de 2025
- **Participação:** Individual (projeto acadêmico para aprovação no semestre)
- **Projeto:** Sistema interativo de estudo da Bíblia e da Igreja Católica, com cadastro e login, leitura, quizzes, mural de interação e recursos para salvar conteúdos favoritos. O projeto acadêmico aborda desenvolvimento web, banco de dados, versionamento e outros conceitos do curso.
- **Mais informações:** [README do projeto](./VerbumDeiProject/README.md)
- **Arquivos:** [VerbumDeiProject](./VerbumDeiProject/)

### SenGas

- **Período:** 1º semestre do curso — 2º semestre de 2025
- **Participação:** Em grupo
- **Projeto:** Solução voltada à identificação de vazamentos de gases no processo de fabricação de biometano e à geração de dados para análises futuras.
- **Mais informações:** [README do projeto](./SenGas/README.md)
- **Arquivos:** [SenGas](./SenGas/)

### Stefanini Quiz Challenge

- **Período:** 2º semestre do curso — 1º semestre de 2026
- **Participação:** Em grupo (projeto acadêmico)
- **Projeto:** Aplicação web de quiz com persistência de respostas em MySQL e ranking de participantes. O projeto permitiu praticar desenvolvimento full stack, integração com banco de dados e versionamento com Git.
- **Mais informações:** [README do projeto](./stefanini-quiz-challenge/README.md)
- **Arquivos:** [stefanini-quiz-challenge](./stefanini-quiz-challenge/)

### SIMECOM Report App

- **Período:** 2º semestre do curso — 1º semestre de 2026
- **Participação:** Individual, desenvolvido como complemento ao projeto acadêmico em grupo
- **Projeto:** Aplicação Java para analisar dados de comércio exterior a partir de arquivos CSV. Aplica filtros, calcula métricas, gera gráficos e produz relatórios em PDF, com suporte opcional a insights por IA.
- **Mais informações:** [README do projeto](./simecom-report-app/README.md)
- **Arquivos:** [simecom-report-app](./simecom-report-app/)

### SIMECOM — Data Loader

- **Período:** 2º semestre do curso — 1º semestre de 2026
- **Participação:** Em grupo
- **Projeto:** Pipeline Java para carregar dados de comércio exterior do MDIC no MySQL, utilizando arquivos armazenados no AWS S3.
- **Mais informações:** [README do projeto](./SIMECOM-Project/README.md)
- **Arquivos:** [SIMECOM-Project](./SIMECOM-Project/)

### Minha Garagem

- **Período:** 3º semestre do curso — 2º semestre de 2026
- **Participação:** Individual
- **Projeto:** Aplicação para cadastrar veículos e suas peças, consultar os veículos cadastrados por usuários e comparar dois veículos.
- **Mais informações:** [README do projeto](./projetoindividual-minhagaragem/README.md)
- **Arquivos:** [projetoindividual-minhagaragem](./projetoindividual-minhagaragem/)

### AquaSense

- **Período:** 3º semestre do curso — 2º semestre de 2026
- **Participação:** Em dupla
- **Projeto:** Protótipo de uma solução para monitoramento inteligente de piscinas, apresentado em uma landing page interativa com indicadores demonstrativos, alertas e recomendações ilustrativas.
- **Integrantes:** Vinicius Francelino e Davi Jeronimo
- **Mais informações:** [README do projeto](./AquaSense/README.md)
- **Arquivos:** [AquaSense](./AquaSense/)
